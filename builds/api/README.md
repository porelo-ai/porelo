# api

The contract between Porelo and a build reader, published as `porelo-build-api`: the interface a reader implements, the server it runs and the client Porelo uses, over the varlink protocol `org.fuin.porelo.Build2`. Its `build` operation returns a commit's verdict and jobs, with logs selected as `none`, `failure` or `all`; its optional `openPullRequest` opens the pull request from a task's branch. It reads no forge itself. It also carries the schemas of the [review profile](../../doc/review-profile.md), versions 1 and 2, and its tests jar the profile 2 fixtures a forge adapter builds against. Writing a reader is in [writing a build reader](../../doc/build-readers.md).

The same executable can answer a pull request's review over `org.fuin.porelo.Review1` on the same socket: a reader that also implements `ReviewReader` serves it beside `Build2`, and one that does not serves `Build2` alone. Its methods are a pull request's facts, the open pull request from a branch, one page of its conversation and one post of a released result, each with the token lent for that call; documents cross as review profile 2, and no method reaches a verdict. Porelo asks it through `InstalledReviewReader`, which refuses another review version and hands every document on as bytes, parsing none. The contract is the description itself, `org.fuin.porelo.Review1.varlink` beside `org.fuin.porelo.Build2.varlink`.
