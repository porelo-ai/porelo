# organization

Where Porelo keeps who may do what: the owners, the people and the hosts. Porelo asks through an API; how it is kept
is the adapter's, which guarantees the security itself.

- [api](api/README.md) - what Porelo asks, saying nothing of how it is kept
- [contract](contract/README.md) - what any store must guarantee, as checks an adapter runs against itself
- [git-tree](git-tree/README.md) - the adapter that keeps it in one Git repository
