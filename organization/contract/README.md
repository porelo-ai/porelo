# organization/contract

What any organization's store must guarantee, as checks an adapter runs against itself through a fixture it gives: every
change signed by the one allowed to make it, whether read or made through the API, a history that cannot be rewritten unnoticed, and a host's offline check
against its pinned key. It speaks the [api](../api/README.md) alone and must never need `git` or a class of an adapter.
Its own tests run every check against a stand-in that breaks what the check guards.
