# organization/git-tree

The organization of the new structure, kept in one Git repository: `owners.yml`, `people/`, and each project's card and
members. Its history is walked path by path against who may change each path, and every question is answered from what
that walk accepted. It reads only and never opens a project's repository. It needs nothing of
[git](../git/README.md), which keeps today's layout until the cut.
